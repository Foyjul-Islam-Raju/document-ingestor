Processing pipeline

Clear results for digital, scanned, and structured files.

02 · Extract
  1. Validate each file. Damaged, encrypted, empty, or unsupported files receive a clear per-file status.
  2. Read every PDF page. Embedded text is extracted directly; scanned pages use OCR.
  3. Improve image readability. Images and TIFF frames are cleaned up before recognition.
  4. Parse structured data. Every workbook sheet is read; CSV encoding and delimiter are detected.
  5. Review and search. Inspect page text and row previews, then search saved extraction results.
